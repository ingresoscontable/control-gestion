Estado

Se hace un respaldo cada {{ horas }} hora(s), además de uno cada vez que se arranca el sistema. Se conservan los últimos {{ conservar }} y los más viejos se borran solos.

Base de datos: {{ archivo_base }}
Carpeta de respaldos: {{ carpeta }}

Cómo funciona

  • La copia se hace con la API de SQLite, así que sale consistente aunque alguien esté cargando datos.
  • Para guardar los respaldos en otro lado (pendrive, carpeta de red) define la variable CG_BACKUP_DIR antes de arrancar. Ejemplo en iniciar.bat: 
    set CG_BACKUP_DIR=D:\Respaldos\ControlGestion
  • Para cambiar la frecuencia usa CG_BACKUP_HORAS y para cuántos conservar, CG_BACKUP_CONSERVAR.
  • Para volver atrás, pulsá Restaurar en la tabla de abajo: se reemplaza toda la base por ese respaldo. Antes de reemplazarla el sistema deja una copia de seguridad del estado actual, así que también se puede volver a esa copia.
